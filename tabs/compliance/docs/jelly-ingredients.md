# Reboot 젤리(구미형) 원료 검토 — 미국 일반식품 기준

- 작성: 2026-10-25 · 소준희 (컴플라이언스)
- 참고 자료
  - ① 미국의 '술 마시기 전' 구미 (Undo · 2 gummies 10 g)
  - ② 미국 스틱 젤리
  - 두 제품 모두 라벨이 **Supplement Facts**인 **건강기능식품**입니다.
- **우리 제품의 확정 배합이 아닙니다.** Reboot는 일반식품(브랜드 가이드 v1.1)이라, 건강기능식품에 든 원료라고 해서 그대로 넣을 수 없습니다.
- 1차 판단입니다. 최종 판단은 알디콤 배합 자료와 원료별 GRAS 근거로 확인합니다. 법률 자문이 아닙니다.
- 판단 결과는 컴플라이언스 › 규칙·검증 › **원료 표**의 '젤리' 칸에도 같은 내용으로 들어 있습니다.

## ✅ 바로 쓸 수 있는 원료 (구미 기본 배합)

| 원료 | 비고 |
|---|---|
| 설탕(사탕수수당) · 타피오카 시럽 · 물엿 | **Original만** 씁니다. Balance(Zero Sugar)에는 넣지 않습니다. |
| 승인 감미료 (수크랄로스·스테비아 Reb M·알룰로스 등) | Balance용입니다. 'Zero Sugar'는 1회 제공량당 당 0.5 g 미만이어야 하고, 조건부로 관리합니다. |
| **펙틴** (+ 구연산·구연산나트륨) | 구미 겔화제입니다. 비건 대응이 됩니다. **곤약 대신** 씁니다. |
| 정제수 · 구연산 · 사과산 | 신맛을 냅니다 (레몬·라임). |
| 코코넛 오일(MCT) · 해바라기 레시틴 | 코팅·이형제입니다. 코코넛은 2025년 FDA 지침 개정으로 견과류 목록에서 빠졌는데, 알레르기 표시 여부는 다시 확인합니다. |
| 천연향 (라임·레몬·체리) | 'natural flavor'로 표시합니다. 맛은 브랜드 가이드의 3가지만 씁니다 (망고 제외). |
| 색소: **강황 추출물(노랑)** · 채소·과일즙 색소(분홍·연두) | 천연 색소입니다. **적색 3호는 2027년 1월부터 식품에 쓸 수 없고**, 적색 40호는 일부 주에서 제한합니다. |

## ⚠️ 조건부 원료

| 원료 | 확인할 것 |
|---|---|
| **헛개나무 열매·추출물 · A-HAT** (우리 확정 원료) | 브랜드 가이드상 확정 원료지만 **미국 원료 근거는 확인 전**입니다. 헛개는 FDA 공개 GRAS 통지가 0건이고 알디콤 근거 문서도 확인하지 못했습니다. L. fermentum은 균주를 확인하지 못했습니다 → 근거가 확인되면 ✅로 올립니다. 문구에서 내세우면 함량(%) 표시를 요구받을 수 있습니다 (R13). |
| 비타민 B12 · 아연 · 마그네슘 | 원료 자체는 허용됩니다. 다만 FDA 영양 강화 정책(21 CFR 104.20)은 **사탕·간식류에 영양소를 넣는 것을 적절하지 않다고 봅니다.** 넣으면 %DV 표시 의무가 생깁니다. 참고 제품의 B12 200%, 아연 55%는 건강기능식품 수준의 양입니다. |
| 유산균 L. fermentum (A-HAT) | 구미를 만들 때 열을 가하면 균이 죽을 수 있습니다. 열처리균인지, 균주명은 무엇인지 확인합니다. |
| 생강 · 타우린 | 식품에 쓸 수 있지만 맛과 효능 표현을 함께 확인합니다. |

## ❌ 쓰지 않는 원료

| 원료 | 이유 |
|---|---|
| **DHM** (헛개에서 뽑은 디하이드로미리세틴) | 2020년 FDA 숙취 경고장이 숙취 예방 성분으로 광고된 사례로 직접 인용했습니다. 우리 원료는 헛개 '열매·추출물'이고, DHM 단일 성분이 아닙니다. |
| **밀크시슬** | 간 보호 이미지가 강하고, 일반식품에 쓸 근거가 필요합니다. |
| **곤약** | 우리는 구미형으로 정했습니다. 곤약 젤리는 FDA 수입 경보 33-15 대상입니다. |
| **엽산** | 일반식품은 넣을 수 있는 식품이 정해져 있고(21 CFR 172.345), 젤리는 해당하지 않습니다. |
| 글루타치온 · 아티초크 · NAC | 일반식품 근거가 없거나 간·해독 이미지가 강합니다. |

- 원재료는 많이 들어간 순서대로 모두 적습니다 (21 CFR 101.4). '비공개 배합(Proprietary Blend)'은 건강기능식품 라벨 방식이라 쓰지 않습니다.
