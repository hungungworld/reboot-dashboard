# Reboot 음료 원료 검토 (미국 일반식품 기준)

- 작성: 2026-10-25 · 소준희 (컴플라이언스)
- 참고 자료: 국내 헛개 음료(100 mL · 혼합음료)의 원재료 표시. **우리 제품의 확정 배합이 아닙니다.**
- 기준: 미국 **일반식품(Conventional Food)**. 브랜드 가이드 v1.1에 따라 Reboot는 일반식품이고, 건강기능식품이 아닙니다.
- 1차 판단입니다. 최종 판단은 알디콤 배합 자료와 원료별 GRAS 근거로 확인합니다. 법률 자문이 아닙니다.
- 판단 결과는 컴플라이언스 › 규칙·검증 › **원료 표**의 '음료' 칸에도 같은 내용으로 들어 있습니다 (`static/data.js` `ingredients`).

## ⚠️ 조건부 원료 (확인한 뒤 사용)

| 원료 | 확인할 것 |
|---|---|
| **헛개나무 열매 추출농축액** (우리 확정 원료) | 브랜드 가이드상 확정 원료지만 **미국 원료 근거는 확인 전**입니다. FDA 공개 GRAS 통지가 0건이고 알디콤 근거 문서도 확인하지 못했습니다 → 근거가 확인되면 ✅로 올립니다. 문구에서 내세우면 함량(%) 표시를 요구받을 수 있습니다 (R13). |
| 미배아발효추출물 (미강·쌀눈·대두펩타이드) | 발효 추출물의 GRAS 근거를 확인합니다. **대두가 들어 있어 라벨에 "Contains: Soy"를 반드시 적어야 합니다.** |
| 타우린 | 미국 음료에 흔히 쓰입니다. 효능 표현은 쓰지 않습니다. |
| 감초뿌리 | GRAS이지만 글리시리진 양에 제한이 있습니다. |
| 니코틴산아미드 (비타민) | 영양 강화 정책(21 CFR 104.20)에 해당하는지, %DV 표시 의무가 생기는지 확인합니다. |
| DL-알라닌 | 미국에서는 쓸 수 있는 용도가 제한된 첨가물입니다. 용도와 양을 확인합니다. |
| 유산균 L. fermentum (A-HAT) | 산성 음료에서는 균이 살아남기 어렵습니다. 열처리균인지, 균주명은 무엇인지 확인합니다. |
| 합성향료 (혼합과일향·벌꿀향) | 미국 라벨에는 **"artificial flavor"**로 적습니다. 'natural'로 쓸 수 없고, 벌꿀향을 꿀처럼 보이게 하면 안 됩니다. |
| 자리추출물 · 복합허브추출물C | 무엇이 들었는지 알 수 없는 원료입니다. **규격서를 받아야** 판단할 수 있습니다. |

## 표시할 때 주의할 점
- 참고 제품의 영양정보(60 kcal · 당류 11 g)는 **우리 제품의 수치가 아닙니다.** 가이드에 있는 참고 수치(약 43 kcal · 당 약 10 g)도 마찬가지로 문구에 쓰지 않습니다 (R15).
- 원재료는 많이 들어간 순서대로 모두 적습니다 (21 CFR 101.4). 'A-HAT'이라는 이름 하나로 성분 표시를 대신할 수 없고, 실제 원료 이름을 적어야 합니다.
- 알레르기 성분은 미국 9대 알레르기(우유·달걀·생선·갑각류·견과·땅콩·밀·대두·참깨) 기준으로 표시합니다.
